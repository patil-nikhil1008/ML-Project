Technical Performance Analysis

Model Architecture Choices: A multi-layer feedforward network with dimensional tapering [3072 → 512 → 256 → 128 → 3] was selected to compress high-dimensional raw pixel features into hierarchically abstract representations. He normal initialization provides variance preservation across ReLU layers, preventing vanishing gradients. Batch Normalization before each non-linearity eliminates internal covariate shift and accelerates optimization, while Dropout (rate=0.3) combined with L2 weight decay (1e-4) penalizes co-adaptation of neurons on dense pixel inputs.

Training Behavior & Convergence: Mini-batch Adam optimization (batch size 128) paired with a Cosine Annealing learning rate schedule ensures fast initial loss reduction followed by fine-grained convergence. Batch normalization stabilizes gradients throughout all 50 epochs, eliminating exploding gradient issues. Validation accuracy closely mirrors training accuracy without severe overfitting, demonstrating that inverted dropout and weight decay successfully regularize the 1.7M parameters.

Per-Class Performance Differences: Automobiles (Class 1) consistently achieve the highest precision and recall (>85%) owing to distinct rectangular silhouettes, high-contrast dark tires, and consistent ground-plane placement. In contrast, Airplanes (Class 0) and Birds (Class 2) exhibit mutual confusion; both share open sky backgrounds with high blue/cyan channel values and elongated aerodynamic profiles, making linear separation on raw pixel coordinates challenging without spatial convolutions.

Potential Improvements: Transitioning to Convolutional Neural Networks (CNNs) with 2D spatial weight sharing, incorporating data augmentations (random horizontal flips, crops, and color jittering), and employing residual skip connections would markedly elevate spatial feature extraction and push classification accuracy beyond 85-90%.
